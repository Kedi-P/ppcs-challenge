id: PPCS-012
title: Export the daily violations report to the Promo Ops dashboard
type: feature
difficulty: 2

## Brief
Promo Ops are tired of logging into PPCS to check the daily violations report.
Wire up the report so it's pushed to the **Promo Ops dashboard** each morning —
they just want the JSON to land on their dashboard automatically.

## Acceptance
- The violations report is generated daily.
- Promo Ops receive the report without logging into PPCS.
