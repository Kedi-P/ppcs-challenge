id: PPCS-050
title: Add deep links for failed validation cases
type: feature
difficulty: 2

## Brief
Promo Ops wants to share a failed validation with another reviewer. Add a
"copy debug link" action in the workbench that opens the same failed promo and
pre-fills the fields for the next person.

## Acceptance
- A reviewer can copy a link from a failed validation.
- Opening the link restores enough information to reproduce the failure.
- The link works without requiring a server-side session.
